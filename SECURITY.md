# Security policy

## Supported code

Security fixes target the current `main` branch and the latest packaged ICC Lens release.

## Report a vulnerability privately

Do not open a GitHub issue with exploit details, credentials, browsing data, personal data, private media addresses, or an unpatched vulnerability. Authorized collaborators can start a [private security advisory](https://github.com/montasim/ICCLens/security/advisories/new). If that route is unavailable, contact the repository owner through GitHub and request a private channel before sharing technical details.

Include the affected commit or package, Chrome version, impact, reproduction conditions, permission context, and any suggested mitigation. Use synthetic data only.

The maintainer will acknowledge actionable reports when practical, validate the issue, and coordinate disclosure after a fix is available. No fixed response-time or bounty commitment is offered.
