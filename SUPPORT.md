# Support

ICC Lens supports Chrome 120+ and the private ICC server at `http://10.16.100.244/`.

- For a reproducible defect, open an [ICC Lens issue](https://github.com/montasim/ICCLens/issues) with Chrome, Node.js, and pnpm versions, the affected ICC page kind, the observed result, and a synthetic reproduction when possible.
- For usage questions, open an issue and clearly label it as a question.
- For a suspected vulnerability, follow [SECURITY.md](SECURITY.md) and do not disclose it in an issue.
- For Chrome, WXT, package-manager, server availability, or Web Store behavior outside this repository, consult the upstream owner first.

Do not attach credentials, cookies, private media addresses, browsing data, or copyrighted media to an issue.
